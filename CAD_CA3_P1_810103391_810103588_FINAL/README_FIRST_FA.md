## نکات تحویل

- فایل‌های محافظت‌شده `.vp`، تست‌بنچ اصلی و `Assembler.py` داخل بسته نیستند؛ این‌ها فایل‌های اولیه درس هستند و تغییری نکرده‌اند.
- `data50.mem` اصلی داخل پوشه `Tests` وجود دارد.
- برای هر تست هم سورس `.s` و هم خروجی `.mem` وجود دارد.
- گزارش HTML کاملاً آفلاین باز می‌شود و وابستگی اینترنتی ندارد.
- بسته شامل تصویر واقعی پنجره ModelSim نیست؛ شاهد واقعی موجود، فایل متنی خروجی ModelSim است. اگر صورت سؤال صراحتاً Screenshot پنجره ModelSim خواسته باشد، باید تصاویر جداگانه قبل از ارسال نهایی افزوده شوند.
